# TP4_Git_Github

Repositorio para practicar el uso de Git y GitHub mediante trabajos prácticos (TP) y notebooks de clase.

## Estructura de carpetas

- **Clase_DeepNote**: Material y notebooks preparados en DeepNote.

- **Clase_PythonLibrerias**: Notebooks y recursos sobre bibliotecas de Python.
	- Notebooks: Clase 5 - Notebook_Workshop_Python_Librerias.ipynb
	- Dependencias opcionales: requirements_opcionales.txt
	- Datos de ejemplo: data/ (encuesta.csv, pagina_demo.html, serie.csv)

- **Clase_PythonRepaso**: Materiales de repaso de Python.
	- Notebooks: Bases_de_Programación.ipynb

- **TP_grupal**: Trabajos prácticos en grupo y datos asociados.
	- Referencia: linkNotebookTP1.txt
	- Datos: data/ (Ciclovias.csv, Coffe_sales.csv, farmacias2021.csv)

- **TP_individuales**: Entregas y ejercicios individuales.
	- Notebooks de ejemplo: 0001 Deepnote.ipynb, 002 – Python Repaso.ipynb, 003 – Python Librerias.ipynb
